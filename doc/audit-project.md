# audit-project.sh

Полный аудиторский отчёт по проекту workspace в файл вне репозитория.

## Вызов
    bin/admin/audit-project.sh <slug>
Пример: bin/admin/audit-project.sh archive

## Поведение
- Отчёт: data/audits/<slug>-<YYYYmmdd_HHMMSS>.txt (в коммиты не попадает).
- Содержимое отчёта: pwd, ветка и последний коммит, версия PHP, список файлов без .git,
  data/, composer.json, содержимое всех файлов, последние 20 коммитов.
- В терминал: путь отчёта, размер, первые 50 файлов, masked-сводка строк, похожих на секреты
  (значения заменяются на [скрыто]).

## Ограничения
- set -eu; требует подключённый common.sh (HUB_ROOT, PROJECTS_DIR).
- Отчёт может содержать секреты в открытом виде внутри файла — храните data/audits локально.
