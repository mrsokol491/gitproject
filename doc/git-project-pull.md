# git-project-pull.sh

Безопасное обновление локальных репозиториев из основного хоста.

## Вызов
    bin/git-project-pull.sh
Аргументов и флагов нет.

## Поведение
1. Хаб: fetch origin + pull --ff-only текущей ветки.
2. Каждый проект в projects/: fetch origin + pull --ff-only; пропуск detached HEAD
   и не-git каталогов.
3. Сводка: успешно обновлено / пропущено.

## Ограничения
- ЗАПРЕЩЕНО запускать через sudo.
- --ff-only предотвращает случайные merge-коммиты.
- Использует remote origin: на устройствах без origin выводится предупреждение
  «хаб не обновлён»; для мульти-хост обновления используйте gitproject-update.sh.
