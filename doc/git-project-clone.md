# git-project-clone.sh

Интерактивное клонирование проекта с выбором Git-хоста.

## Вызов
    bin/git-project-clone.sh
CLI-флагов нет: только пошаговый wizard.

## Шаги
1. Выбор хоста-источника (ОТКУДА клонировать), опционально только ready.
2. Уточнение локального имени каталога (КУДА сохранить).
3. Обработка существующего каталога с понятными вариантами.
4. Добавление дополнительных remote для мульти-хост синхронизации.
5. Итоговое резюме перед выполнением.

## Ограничения
- Весь интерактив в stderr.
- Отмена: q на любом шаге выбора.
