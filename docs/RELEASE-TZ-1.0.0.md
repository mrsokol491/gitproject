## 2. Защита от уязвимостей PHP2Shell (CVE-2026-109618 / CVE-2026-109619)

В связи с выявленными недавними уязвимостями в PHP (перехват управления оболочкой через уязвимости парсинга запросов), необходимо выполнить следующие мероприятия:

- [ ] **2.1.1** Аудит версии PHP на сервере: убедиться, что версия >= патчной версии, закрывающей CVE-2026-109618 и CVE-2026-109619
- [ ] **2.1.2** Аудит конфигурации `php.ini`:
  - `disable_functions`: проверить наличие `exec, system, shell_exec, passthru, popen, proc_open, pcntl_exec`
  - `open_basedir`: установить изоляцию (например, на `~/gitproject/public/`) для веб-выполнения
  - `allow_url_include=Off`
  - `cgi.fix_pathinfo=0` (защита от атак с Path-Info)
- [ ] **2.1.3** Аудит кода (`router.php` и `bin/*.sh`):
  - Исключить передачу переменных URI, Query-string или заголовков в shell-функции
  - Убедиться, что скрипты используют экранирование аргументов или массивы аргументов вместо конкатенации строк в `sh -c`
- [ ] **2.1.4** Зафиксировать версию PHP и статус защиты от PHP2Shell в `README.md` и `STANDARD.md`
