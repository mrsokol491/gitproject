# План исправлений GitProject Workspace Hub

## Проблемы
1. **Неверное отображение названий и описаний** — `loadProjects()` в `public/index.php` передаёт объект как строку (`[object Object]`) вместо использования полей `p.name`, `p.description`, `p.slug`
2. **Нет обновления самого GitProject Hub** — отсутствует механизм проверки и применения обновлений к корневому репозиторию
3. **Нет pull из удалённых репозиториев** — синхронизация только push, нет возможности получить обновления из remote

## Решение

### Шаг 1: Добавить `--pull` в `bin/git-project-sync.sh`
- Добавить флаг `--pull` в парсинг аргументов
- Добавить функцию `pull_project_remote()` — fetch + merge с краткой сводкой изменений
- Поддержка `--pull --remote <name>` для выбора конкретного remote

### Шаг 2: Добавить режим `pull` в `public/api/sync.php`
- Расширить валидацию режима: `'all', 'specific', 'pull'`
- Конструкция команды: `--pull` или `--pull --remote <name>`

### Шаг 3: Создать `public/api/hub_update.php` (новый файл)
- `GET ?action=status` — проверка обновлений (fetch origin, сравнение коммитов, сводка файлов)
- `POST ?action=pull` — применение обновлений (git pull --no-edit origin <branch>)
- Возврат: ветка, коммит, количество обновлений, список последних коммитов

### Шаг 4: Обновить `public/index.php` — фронтенд
**4a. Исправить `loadProjects()`** — использовать `p.slug`, `p.name`, `p.description`
**4b. Добавить секцию "GitProject Hub"** — кнопка "Проверить обновления", отображение статуса
**4c. Добавить CSS** — стили для карточки Hub
**4d. Добавить JS функции:**
- `checkHubStatus()` — проверка обновлений Hub
- `applyHubUpdate()` — применение обновлений Hub
- `syncPull(slug, remote)` — pull из конкретного remote
- `syncPullAll(slug)` — pull из origin
**4e. Автопроверка при загрузке** — `checkHubStatus()` при инициализации

### Шаг 5: Верификация
- Карточки проектов: корректные имена, описания, бейджи веток, кнопки pull
- Hub: статус, проверка обновлений, применение с краткой сводкой
- Pull: fetch + merge, отображение количества изменённых файлов

## Ключевые файлы
| Файл | Действие |
|------|----------|
| `public/index.php` | Исправить рендеринг, добавить Hub UI, pull-кнопки |
| `public/api/sync.php` | Добавить режим `pull` |
| `public/api/hub_update.php` | **Новый** — API обновления Hub |
| `bin/git-project-sync.sh` | Добавить `--pull` и функцию pull |

## Подход
- Merge для pull (не rebase)
- origin для обновления Hub
- Краткая сводка (количество файлов, последние коммиты) перед применением
